구월경희한의원

원내 태블릿 문진

직원용 시작 화면

1. 작성할 문진표 고르기

2. 차트번호 (선택)

입력하면 응답 시트에 함께 기록됩니다. 환자 화면에는 보이지 않습니다.

사용 방법
① 문진표를 고르고 [환자에게 건네기]를 누른 뒤 태블릿을 환자에게 드립니다.
② 여러 개를 고르면 번호 순서대로 이어서 작성합니다. 성명·생년월일은 한 번만 입력합니다.
③ 다 쓰면 "태블릿을 데스크에 돌려주세요"가 뜨고, 10초 뒤 이 화면으로 돌아옵니다.
④ 2분 30초 동안 입력이 없으면 확인 창이 뜨고, 30초 뒤 내용을 지우고 이 화면으로 돌아옵니다.
작성 내용은 태블릿에 남지 않으며, 제출된 응답은 원장님 계정의 응답 시트에서만 볼 수 있습니다.
문진표를 골라 주세요
