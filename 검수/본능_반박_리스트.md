# 본능·반박 리스트 (홈페이지 칼럼용 요약)

전체 표와 근거는 원장님 문서 "한의원 진료 본능 분석·반박 제거 리스트"(claude.ai)에 있습니다. 칼럼마다 주제와 맞는 반박 2~3개를 골라 소제목·FAQ로 답합니다.

## 공통
- 효과: 한약이 정말 효과 있나 / 과학적 근거 / 양방에서 못 고쳤는데 / 나 같은 경우(오래됨·고령·아이)도
- 기간: 끝이 없는 거 아닌가 → 보통 1~3개월, 15일마다 경과 확인
- 부담: 간 나빠지지 않나 → 처방 전 혈액검사 / 양약과 같이 → 복용 약 확인
- 과잉진료: 필요 없는 것까지 → 다른 진료 먼저인 경우 안내 / 몇 달치 결제 → 중단 시 15일 단위 차감 환불
- 비용: /npay/ (한약 1개월 55만~120만 원, 첫 검사 2만 원, 한약 실손 불가)
- 신뢰: 이 병을 많이 봤나 → 2014년부터, 매달 600명 이상, 한 해 1,000명 넘는 이명 환자 / 다른 사람이 보지 않나 → 대표원장 직접

## 이명
평생 안고 가야 한다던데 / 몇 년 된 것도 되나 / 소리가 아예 없어지나 / 보청기·약과 같이 / 갑자기 한쪽이 안 들리면(돌발성 난청: 이비인후과 먼저, 한약 함께) / 잠 못 자는 게 더 힘든데

## 어지럼증·이석증
정복술 받으면 되는데 왜 한의원 / 벌써 여러 번 재발 / 이석 녹이는 약인가 / 돌아갔는데 계속 멍함 / 메니에르는 평생 관리 / 뇌 문제면(응급 증상) / 일어설 때만 어지러움(기립성)

## 하지불안증후군
도파민제 끊어야 하나 / 디스크·하지정맥류 치료했는데 그대로 / 철분 부족 때문(원내 검사에 페리틴 없음 → 내과 검사 권유) / 아이에게 한약 / 성장통과 구분 / 신경과 가야 하나 / 평생 가는 병
